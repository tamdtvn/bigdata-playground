# ADR - Architecture Decision Record - ADR

## Example:
    ADR-001: Why We Choose Docker Compose Instead of Kubernetes

## Status:
    Accepted

## Context:
    We need a local development environment.

## Decision:
    Use Docker Compose.

## Consequences:
    + Easy to learn
    + Lightweight
    - Not production orchestration
